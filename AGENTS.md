## Project Identity

**Little Alif** — Arabic alphabet (Hijaiyah) learning app for children ages 3–6.

- **Stack:** TanStack Start (React 19 + SSR), SQLite (Drizzle ORM), Tailwind v4, Better Auth, Zustand
- **Auth:** Email/password via Better Auth with HttpOnly cookies (30-day session)
- **i18n:** typesafe-i18n (English + Indonesian, parent UI only)
- **Audio:** Web Speech API (`AudioEngine` singleton with `ar-SA` voice preference)
- **PM:** pnpm (not npm/yarn), Node >= 20

## Architecture Snapshot

### Routes (TanStack Router, file-based)

| Path             | Auth                            | Purpose                                 |
| ---------------- | ------------------------------- | --------------------------------------- |
| `/`              | None (redirects if authed)      | Landing → login or child-mode redirect  |
| `/login`         | None                            | Parent login                            |
| `/register`      | None                            | Parent registration                     |
| `/dashboard`     | Parent JWT                      | Profile CRUD + letter toggle management |
| `/learn`         | Parent JWT or child-mode cookie | Child letter grid with tappable cards   |
| `/learn/reading` | Parent JWT or child-mode cookie | Reading practice (Iqra' mode)           |
| `/api/auth/$`    | N/A                             | Better Auth catch-all HTTP handler      |

### Data Layer

- **Tables:** `letters` (28 seeded), `profiles` (max 4/parent), `letter_toggles` (per-profile ON/OFF)
- **Auth tables:** `user`, `session`, `account`, `verification` (Better Auth managed)
- **Pattern:** Pure helper functions accept `(db, userId, ...)` + thin server function wrappers handle session validation. See `app/server/letters.ts` or `app/server/profiles.ts`.

## Conventions & Quirks

### Code Patterns

- **TDD:** Write failing test → implement → pass → (refactor). Tests live next to source files as `*.test.ts`/`*.test.tsx`.
- **Coverage target:** ≥80% lines/statements/branches/functions (`vitest.config.ts` sets thresholds). Routes and generated files excluded.
- **Server functions:** Always `createServerFn({ method: 'GET'|'POST' })` with `.inputValidator(zodSchema)`. Pure helper functions take `(db, userId, ...)` for testability.
- **Auth guards:** Use `requireParentSession(session)` for parent-only, `authorizeChildAccess(session, profileId)` for child-mode.
- **UUID generation:** `crypto.randomUUID()` in schema `$defaultFn`. All profile IDs are UUIDs (validated by Zod schemas).
- **Harakat composition:** `composeLetter(baseChar, vowelMode)` — pure function returning string. No React component. 7 non-connecting letters have precomposed fallbacks (ا و ي ر ز د ذ).

### Testing

- **Vitest** with jsdom environment for components, `node` environment for server/DB tests.
- **DB tests** use in-memory SQLite (`@libsql/client` sync driver). See `app/server/*.test.ts` for patterns.
- **Audio tests** use `createMockAdapter()` — no browser needed.
- **Component tests** verify accessibility attributes (`aria-label`, `aria-pressed`, `role`), touch targets (`min-h-[64px]`), and loading/error states.
- **Meta-tests** in `app/lib/tooling/quality-hooks.test.ts` validate tooling config.

### Naming

- `SCREAMING_SNAKE_CASE` for i18n translation keys (typesafe-i18n convention)
- `camelCase` for everything else
- Generated route tree: `app/routeTree.gen.ts` (auto, not hand-edited)
- Generated i18n files: 8 files in `app/lib/i18n/` (ignored by ESLint + Prettier)

### Design Tokens (Tailwind v4 custom theme)

Colors: `green`, `green-light`, `green-dark`, `sand`, `sand-light`, `sand-dark`, `orange`, `orange-light`, `coral`, `background-warm`, `text-dark`, `text-muted`
Radii: `rounded-small` (10px), `rounded-large` (24px)
Shadows: `shadow-card`, `shadow-large`
Fonts: `font-latin` (Nunito), `font-arabic` (Cairo, Noto Sans Arabic)

### Target Personas

- **Child (3–6, pre-literate):** Zero text UI, large touch targets (≥64x64dp), instant audio feedback
- **Parent:** Bilingual (EN/ID), clear status, simple CRUD

### Letter ID distinction

- `ha` = ح (throaty ḥāʼ, displayOrder 6)
- `hae` = ه (soft hāʼ, displayOrder 27) — name avoids primary key collision
